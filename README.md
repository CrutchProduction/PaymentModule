## Использование

>### **Операции**
Главное окно приложения разделено на две основные области: навигационный список доступных операций (слева) и панель выбранной операции (справа). Сверху отображается информация о текущем счёте пользователя, его балансе и валюте.

При выборе операции в списке отображается соответствующая панель с полями ввода, кнопкой выполнения и индикаторами валидации.

>#### **Перевод на другой счёт**
Позволяет перевести средства с текущего счёта на другой счёт.
- **Номер счёта** — отображается автоматически (только для чтения).
- **Номер счёта куда перевести** — поле ввода счёта получателя.
- **Сумма перевода** — поле ввода суммы перевода.

После заполнения полей необходимо нажать кнопку **«Перевести»**. Рядом с кнопкой отображается индикатор постусловия.

>#### **Перевод в другую валюту**
Позволяет конвертировать средства текущего счёта в выбранную валюту.
- **Номер счёта** — отображается автоматически (только для чтения).
- **Валюта** — выпадающий список с доступными валютами: Российский рубль ₽, Евро €, Доллар $, Юань ¥.

После выбора валюты необходимо нажать кнопку **«Конвертировать»**. Рядом с кнопкой отображается индикатор постусловия.

>#### **Пополнение**
Позволяет пополнить баланс текущего счёта.
- **Номер счёта** — отображается автоматически (только для чтения).
- **Сумма** — поле ввода суммы пополнения.

После ввода суммы необходимо нажать кнопку **«Пополнить счёт»**. Рядом с кнопкой отображается индикатор постусловия.

>#### **Снятие**
Позволяет снять средства с текущего счёта.
- **Номер счёта** — отображается автоматически (только для чтения).
- **Сумма** — поле ввода суммы снятия.

После ввода суммы необходимо нажать кнопку **«Снять»**. Рядом с кнопкой отображается индикатор постусловия.

>### **Контракты**
Для каждой операции доступна кнопка **«Показать контракт»**, при нажатии на которую открывается панель с описанием контракта операции, содержащая:
- **Предусловия** — условия, которые должны быть выполнены до операции.
- **Постусловия** — условия, которые должны быть выполнены после операции.
- **Эффекты** — изменения состояния системы.
- **Исключения** — возможные ошибочные ситуации.
- **Граничные примеры** — валидные и невалидные примеры выполнения операции.

>### **Индикаторы валидации**
Рядом с полями ввода и кнопками выполнения операций отображаются цветные прямоугольники, показывающие состояние валидации:
- **Зелёный** — условие выполнено (валидно).
- **Красный** — условие не выполнено (невалидно).

Цвет индикатора задаётся через конвертер `ConditionBrushConverter`, привязанный к соответствующим свойствам валидации ViewModel.
